在本地清晰查看口腔 CBCT 与全景 DICOM

DViewer 是 LuXOne 旗下的 Windows 桌面端医学影像查看程序。 指定包含 DICOM 的文件夹即可递归扫描子目录，自动进入全景浏览或 CBCT 多页工作流，并由 GPU（wgpu）加速显示。

核心功能

以文件夹为中心

支持命令行传入路径，或使用程序标题栏中的文件夹图标选择目录；自动递归扫描子文件夹中的 DICOM。

智能进入模式

扫描到多个 DICOM 时进入 CBCT 外壳（MPR、CPR、Side、TMJ、Report 等 Tab）；单个文件默认走首张全景；若为单文件体数据，启动时可加 --cbct 进入 CBCT。

GPU 加速渲染

基于 wgpu，为二维切片与三维相关视图提供流畅的窗宽窗位与交互基础。

快速开始

  1. 准备数据 — 将病例 DICOM 放在同一文件夹内（可含子目录）。
  2. 启动程序 — 运行 d-viewer.exe 并传入文件夹路径，或使用标题栏「打开文件夹」图标。
  3. 阅片 — 在全景或各 CBCT Tab 中浏览；详细说明见主仓库 DViewer/docs/ 下的用户手册与设计文档。

技术栈

  • Rust
  • iced
  • wgpu
  • DICOM（dicom-rs）
  • Windows

DViewer 在 LuXOne rust-cbct 工作区中开发，与 PatientManager 等组件共享字体与图标资源。

文档与支持

应用源码与说明位于主仓库 DViewer/docs/：DViewer_User_Manual.md（英文用户手册）、CBCT_VIEWER.md（界面与 Tab 约定）。可将 HTML 版手册用 Word 另存为 docx，或使用 Pandoc 导出，详见手册内说明。
